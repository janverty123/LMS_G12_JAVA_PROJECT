BUSINESS PROBLEM
Classroom records and learning resources are handled through a mixture of
paper documents, folders, spreadsheets, and separate communication channels.
This makes it difficult for teachers to organize materials, monitor submissions,
compute grades, and identify students who need support. Students may also miss
announcements, deadlines, or feedback because information is not available in
one central system.

CURRENT PROCESS
Teachers distribute materials and activities manually, record scores in paper
records or Excel files, and check student work one submission at a time.
Announcements and reminders are sent through separate channels. Class lists,
subject records, grades, and progress reports must be updated independently,
which creates duplicate work and increases the risk of missing or inconsistent
information.

DESIRED SYSTEM
Classify: a responsive Learning Management and Student Progress Monitoring
System that centralizes class sections, subjects, learning materials, activities,
submissions, grades, progress, announcements, and notifications. The system
must provide secure role-based access for teachers and students and must keep
grading and authorization rules under backend control.

PROJECT DESCRIPTION
Classify is a responsive web-based learning management and student-progress
system for Lagro High School. It organizes classroom work through the hierarchy
Class Section -> Subject -> Materials, Activities, Grades, and Progress. Teachers
can manage their assigned responsibilities, while students join one class and
receive access only to approved subjects linked to that class.

SCOPE
- Secure teacher and student registration and login
- Role-based backend authorization
- Class-section creation, class codes, and student join requests
- Subject creation and class-to-subject linking requests
- Learning-material posting and direct S3-compatible file uploads
- Activities in exactly three categories: Written Activity, Performance Task,
  and Test
- Student submissions, teacher scoring, and score-request approval workflows
- Backend-controlled grade computation and grade configuration
- Teacher gradebook, student grades, progress monitoring, and Excel export
- Section announcements and persistent user notifications
- Responsive teacher and student interfaces

DELIVERABLES
1. React and TypeScript frontend
2. Java 21 and Spring Boot backend API
3. PostgreSQL database
4. S3-compatible object-storage integration
5. Teacher and student dashboards
6. Class, subject, material, activity, grade, and progress modules
7. Announcements and notifications
8. Excel gradebook export
9. Test results and deployment configuration
10. Project documentation and final handover

TIMELINE
Five-week development timeline, from requirements gathering and wireframing
through implementation, testing, deployment, and client presentation, as
detailed in the Project Planning Schedule and Milestone Matrix.

REVISION LIMITS
Up to two minor revisions are included. Requests that change the agreed scope,
cost, or schedule must be documented and approved through a Change Request.

ACCEPTANCE CRITERIA
The project will be accepted when login, registration, database operations,
